# Malindile's Construction Website

**Project Status: Under Development**

## About the Project

I am independently developing the Malindile Construction Website, a modern and responsive website for a construction company specialising in roofing, cladding, and structural installations for commercial and residential projects.

The purpose of this project is to establish a professional online presence for Malindile, showcase the company's services and projects, and provide potential clients with an accessible way to make enquiries.

I am responsible for the development of this project, including the user interface, page layouts, responsive styling, navigation, and implementation of website functionality.

**This project is still under active development, and I am continuously improving its design, features, and overall user experience.**

## Objectives

My main objectives for this project are to:

- Develop a professional website that represents Malindile's construction services.
- Create a responsive user interface that works across desktop, tablet, and mobile devices.
- Build reusable React components and maintain organised code.
- Showcase construction services and projects in a clear and professional manner.
- Provide a convenient contact page for potential clients.
- Improve my practical skills in front-end development, responsive design, and React application development.

## Features

The following pages are being developed as part of the website:

- **Home Page:** Introduces Malindile and highlights its core construction services.
- **Services Page:** Presents the company's roofing, cladding, and structural installation services.
- **Projects Page:** Provides a dedicated space to showcase construction projects.
- **Contact Us Page:** Displays contact information and includes a project enquiry form.
- **Navigation Bar:** Allows visitors to navigate between the website's main pages.
- **Responsive Layout:** Adapts the website layout to different screen sizes.

These features are being implemented and refined as I continue working on the project.

## Technology Stack

I am using the following technologies to develop the website:

- **React** — Building reusable components and managing the user interface.
- **Vite** — Providing a fast development environment and production build tooling.
- **JavaScript** — Implementing application logic and interactive functionality.
- **CSS3** — Styling the website and creating responsive layouts.
- **Bootstrap** — Supporting responsive layouts and selected interface components.
- **React Router** — Managing navigation between pages.

## Getting Started

To run the project locally, follow these steps.

### Prerequisites

- Node.js
- npm
- A code editor, such as Visual Studio Code

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd malindile
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL provided in the terminal, usually `http://localhost:5173`.
